Resumo

A Nivora é uma extensão criada pela WBCS que substitui a página de nova guia do Microsoft Edge por um painel pessoal e personalizável.

A extensão oferece recursos como mecanismos de pesquisa, histórico de pesquisa próprio, atalhos, ícones personalizados, wallpapers, relógio, saudação, clima, temas claro e escuro, contraste adaptativo e outras preferências visuais.

A Nivora não vende dados, não exibe anúncios, não realiza análise comportamental e não monitora o histórico geral de navegação do Microsoft Edge.

A maior parte das informações permanece no navegador. Alguns dados são enviados a serviços externos somente quando uma função correspondente é utilizada, como pesquisa na web, clima, pesquisa de ícones ou sincronização opcional com Google.

Dados armazenados localmente

Para manter a configuração da nova guia, a Nivora pode armazenar localmente informações como:

  • nome ou apelido usado na saudação;
  • idioma e fuso horário;
  • mecanismo de pesquisa escolhido;
  • URLs de mecanismos de pesquisa personalizados;
  • histórico de pesquisas realizadas pela barra da Nivora;
  • atalhos e seus endereços;
  • favicons e ícones personalizados;
  • wallpapers escolhidos pelo usuário;
  • preferências de tema e contraste;
  • posição, tamanho, transparência e visibilidade dos elementos;
  • cidade configurada para o widget de clima;
  • dados meteorológicos temporariamente armazenados em cache;
  • outras preferências relacionadas à personalização da nova guia.

Esses dados são utilizados somente para fornecer e preservar a experiência configurada pelo usuário.

A análise de luminosidade utilizada pelo tema adaptativo é realizada localmente no navegador a partir do wallpaper exibido. O wallpaper não é enviado a serviços externos para realizar essa análise.

Wallpapers escolhidos pelo usuário não são incluídos no backup opcional do Google Drive.

Pesquisa e histórico

Quando o usuário envia uma pesquisa pela barra da Nivora, o texto digitado é encaminhado ao mecanismo de pesquisa selecionado.

Os mecanismos disponíveis podem incluir Bing, Google, DuckDuckGo ou um mecanismo personalizado configurado pelo próprio usuário.

A Nivora pode manter um histórico local das pesquisas realizadas pela sua própria barra para exibir sugestões enquanto o usuário digita.

Esse histórico é independente do histórico de navegação do Microsoft Edge. A Nivora não lê a lista geral de páginas visitadas pelo usuário.

O histórico de pesquisa pode ser desativado. O usuário também pode remover entradas individuais ou apagar todo o histórico nas configurações da extensão.

Quando a sincronização opcional com Google é utilizada, dados de configuração atualmente suportados pelo sistema de backup podem incluir o histórico de pesquisa da própria Nivora.

Clima

O widget de clima é opcional.

Quando o recurso é ativado, o usuário informa uma cidade. O nome dessa cidade é enviado ao serviço de geocodificação do Open-Meteo para identificar a localização correspondente.

As coordenadas retornadas para essa cidade são então utilizadas para consultar condições meteorológicas atuais, incluindo temperatura, sensação térmica, umidade, vento e condição do tempo.

A Nivora não solicita acesso ao GPS do dispositivo, não usa a API de geolocalização do navegador e não determina automaticamente a localização precisa do usuário.

A localização utilizada pelo widget é a cidade informada manualmente pelo usuário.

Dados meteorológicos podem ser armazenados temporariamente em cache para reduzir consultas desnecessárias e para permitir que o último resultado válido permaneça visível durante falhas temporárias de conexão.

Sincronização opcional com Google

A sincronização com Google é opcional e somente é iniciada depois de uma ação explícita do usuário.

Quando ativada, a Nivora utiliza o fluxo de autorização OAuth do Google e solicita acesso somente à área privada de dados de aplicativo do Google Drive (appDataFolder).

Essa área é destinada aos dados internos de aplicativos e não concede à Nivora acesso aos demais documentos, fotos ou arquivos pessoais armazenados no Google Drive.

  • O endereço de e-mail da conta Google conectada é utilizado somente para identificar a sessão ativa.
  • O token OAuth é mantido temporariamente no armazenamento de sessão da extensão.
  • O token é removido quando expira ou quando o usuário encerra a sessão pela Nivora.
  • O backup pode incluir configurações da extensão, atalhos, ícones personalizados, preferências visuais, histórico de pesquisa da Nivora e configurações relacionadas ao clima, conforme os campos atualmente suportados pelo sistema de backup.
  • Wallpapers não são enviados ao Google Drive.
  • O backup somente é criado, substituído ou restaurado quando o usuário solicita essa ação.

O uso das informações recebidas das APIs do Google segue a Google API Services User Data Policy , incluindo os requisitos de Limited Use.

Serviços externos

Algumas funções da Nivora dependem de serviços externos:

  • Mecanismo de pesquisa selecionado: recebe a consulta quando o usuário envia uma pesquisa. Quando um mecanismo personalizado é utilizado, o destino é definido pelo próprio usuário.
  • Open-Meteo: recebe o nome da cidade configurada para geocodificação e recebe as coordenadas correspondentes para fornecer os dados meteorológicos atuais.
  • Iconify: recebe o termo digitado somente quando o usuário utiliza a função de pesquisar ícones no catálogo.
  • Google APIs: são utilizadas somente depois da autorização opcional do usuário para identificar a conta conectada e salvar ou restaurar dados da Nivora na área privada de dados de aplicativo do Google Drive.
  • Microsoft Edge: fornece favicons associados aos endereços de atalhos informados pelo usuário através da API de favicon do navegador.

O que a Nivora não coleta

A Nivora não coleta:

  • informações financeiras ou de pagamento;
  • informações de saúde;
  • mensagens, e-mails ou comunicações pessoais;
  • senhas digitadas em sites;
  • histórico geral de navegação do Microsoft Edge;
  • conteúdo das páginas visitadas;
  • localização GPS ou localização precisa automática;
  • dados para publicidade comportamental;
  • dados para criação de perfis publicitários;
  • dados para avaliação de crédito ou empréstimos.

O histórico mantido pela Nivora refere-se somente às pesquisas realizadas diretamente por sua própria barra de pesquisa.

A cidade utilizada pelo recurso de clima é informada manualmente pelo usuário.

Retenção e exclusão

Informações armazenadas localmente permanecem no navegador até serem apagadas pelo usuário, substituídas por novas configurações ou removidas com a desinstalação da extensão.

O histórico de pesquisa pode ser apagado separadamente nas configurações da Nivora.

O token OAuth utilizado pela sincronização Google expira automaticamente e também é removido quando o usuário encerra a sessão.

O usuário pode revogar o acesso da Nivora através das configurações da Conta Google.

A revogação impede novos acessos, mas pode não remover automaticamente dados de aplicativo já armazenados. A exclusão desses dados depende dos controles oferecidos pelo Google para aplicativos conectados.

Segurança e compartilhamento

A Nivora utiliza conexões HTTPS para os serviços externos descritos nesta política e solicita apenas permissões relacionadas às funções oferecidas.

A Nivora não vende nem aluga dados de usuários.

Informações não são transferidas para publicidade, perfilamento, avaliação de crédito ou outras finalidades não relacionadas ao funcionamento da extensão.

Dados somente são enviados a serviços externos quando isso é necessário para executar uma função solicitada pelo usuário, como pesquisar na web, consultar o clima, pesquisar ícones ou sincronizar um backup.

Alterações e contato

Esta política poderá ser atualizada quando as funcionalidades da Nivora forem modificadas.

A data da última revisão será sempre indicada nesta página.

Dúvidas, solicitações ou questões relacionadas à privacidade podem ser enviadas ao endereço de suporte publicado na página oficial da Nivora no Microsoft Edge Add-ons.

Privacy Policy Summary

Nivora is a customizable Microsoft Edge new-tab extension created by WBCS.

Nivora does not sell user data, display advertising, monitor the browser's general browsing history, or perform behavioral analytics.

Locally stored information may include greeting preferences, language, time zone, search-engine configuration, Nivora search history, shortcuts, custom icons, wallpapers, weather settings and cached weather data, themes, layout positions, sizes, opacity settings, and other new-tab preferences.

Adaptive wallpaper contrast analysis is performed locally in the browser.

When the user submits a search, the query is sent to the search provider selected by the user. Nivora's optional search history contains only searches performed through Nivora and can be disabled or cleared.

The optional weather widget sends the city entered by the user to Open-Meteo's geocoding service and uses the resulting city coordinates to retrieve current weather information. Nivora does not request GPS or precise device location.

Optional Google synchronization requires explicit user authorization and uses only the private Google Drive application-data area.

The connected Google account email is used only to identify the active synchronization session. The OAuth token is stored temporarily in extension session storage.

Backups may include supported Nivora settings, shortcuts, custom icons, visual preferences, Nivora search history, and weather-related configuration. Wallpapers are not uploaded.

Iconify receives icon-search terms only when the user searches the icon catalog. Microsoft Edge provides favicons for user-created shortcuts.

Data is not used for advertising, profiling, lending, credit decisions, or purposes unrelated to Nivora.

Local data remains until cleared, replaced, or the extension is uninstalled. Google authorization may be revoked at any time.

Support requests may be sent to the contact address shown on the Nivora Microsoft Edge Add-ons listing.
